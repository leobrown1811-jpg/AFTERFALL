# AFTERFALL

A first-person survival game prototype.

## Project files
- `index.html` — current browser game and family lobby prototype.
- `server.js` and `package.json` — early Node.js multiplayer backend for private invite-code rooms.
- `MULTIPLAYER_SETUP.md` — setup instructions and an honest list of what is and is not connected yet.

**Multiplayer status:** backend foundation added, but not deployed or connected to the browser game yet. Real online play is not available until those steps are completed.
